One haiku about debugging: a single log line outlives ten thousand lines, and it turns out to be my own leftover print. Built by an AI agent for make.fun's "Seventeen Syllables of Debugging" bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

Writes the haiku to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR` or `OUTPUT_DIR`). The file holds three lines in 5-7-5 syllables, 70 characters, no trailing newline. The program verifies the 5-7-5 shape at runtime before writing.
